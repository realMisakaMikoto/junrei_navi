# 巡礼手帳 v0.2.5

v0.2.5 新增按地区切换的 Google/高德地图与路线服务，并修复高德地图首次打开时的 JNI 崩溃。版本号为 `versionName=0.2.5`、`versionCode=11`；Room schema 仍为 2。

## 双地图与路线

- 中国大陆及中国官方地图专用区域使用高德地图和高德路线；香港特别行政区、澳门特别行政区、中国台湾、日本及其他地区使用 Google。
- 起点及全部目的地必须属于同一地图提供方，跨提供方行程会提示调整选点。
- 搜索结果跨地区时，可显式切换 Google/高德地图；每张地图只显示对应点位，完整列表和已选地点保留。
- 高德支持驾车、骑行、步行和公交规划，导航按段交给手机上的高德地图。
- 日本公交继续采用本地排序及用户主动的 Google 地图分段交接。
- 高德服务不可用时，可主动选择仅按当前顺序分段打开高德地图；不显示伪造的路线详情或预计时间，也不回退 Google。
- Android 与后端独立校验地区，v2 协议核对提供方、坐标系和地区数据版本。

## 地图与稳定性修复

- 补齐高德 SDK 官方混淆规则，修复原生渲染器找不到 Java 回调类导致的 `GetStaticMethodID / java_class == null` 崩溃。
- 新增 Release JNI 检查，核对关键类、回调方法与字段，并检查最终 APK 的 DEX 类定义。
- 修复横屏地图失败后未真正切到列表，以及底部视图状态显示错误的问题。
- 将后端接口不存在的 404 正确识别为后端故障，不再误报两家路线提供方同时不可用。
- 测试包构建前检查配套 v2 后端，避免交付无法连接路线服务的安装包。

## 安装与升级

- 支持 Android 8.0（API 26）及以上版本。
- 从 v0.2.4 或之前的 v0.2.5 测试包更新时，请直接覆盖安装，不要卸载或清除数据。
- 沿用固定签名，Room schema 保持 2；已保存的作品、点位、设置、行程顺序和导航进度保留，继续旧行程前会重新判区和刷新路线。
- 高德地图需要单独同意 SDK 隐私授权，分段导航需要安装高德地图；Google 地图与应用内道路导航依赖 Google Play 服务。

## 网络、费用与隐私

- 高德 Web 服务密钥和签名材料仅在后端使用；Android 使用独立 SDK Key。
- Google 与高德路线详情只驻留内存，持久化坐标保持 WGS84，高德 GCJ-02 路线仅绘制在高德地图上。
- Analytics 和 Crashlytics 继续默认关闭，可分别选择加入或撤回。
- 路线服务采用共享额度及 HMAC-IP 限速，不设置个人每日额度。
- 当前高德转换、逆地理编码、距离和路线四类调用各限每日 200 次、每月 200 次；Google 月度上限为 9,000 个矩阵元素、9,000 次路线查询、900 个导航目的地预留。多点行程可能消耗多次调用，服务不保证不限量可用。

完整说明见[隐私政策](https://github.com/realMisakaMikoto/junrei_navi/blob/main/PRIVACY.md)。

## 已知限制与验收

- 中国大陆公交不支持指定到达时间与任意交通工具组合筛选；其他地区以提供方实际数据覆盖为准。
- 地区数据不确定、版本不一致、跨提供方或配额不足时会停止请求，本地进度保留。
- 本次直接发布已通过检查的签名构建；维护者于 2026-09-10 确认手动测试正常并批准发布，没有重新运行构建或 CI。
- 原有 PR/main CI、API 26/37、R8/JNI、签名与 APK 检查已通过；后端 Google/高德真实路线联调已通过。维护者的人工验收与自动测试分别记录。
