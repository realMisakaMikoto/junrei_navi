# 巡礼手帳 v0.2.5

本文件是候选发布说明草稿。授权、地区数据许可与地图审核、GPL/高德 SDK 分发处理、独立生产密钥与额度、真实提供方隔离、实体设备和签名覆盖升级证据完成前，不得删除首行或用于 GitHub Release。

## 候选变化

- 按完整行程地区互斥选择地图与路线提供方；中国大陆/经批准的中国官方地图专用区使用高德，其他地区使用 Google。
- Android 与后端独立校验同一版本地区数据；无法解析、边界不确定、跨提供方或版本不一致时 fail closed。
- API v2 返回显式提供方、坐标系和地区数据版本，并拒绝客户端选择提供方、旧地区版本或过旧客户端。
- 用户点位、行程和外部地图交接保持 WGS84；高德 GCJ-02 路线只存在于内存并只在高德地图绘制。
- 中国驾车、公交、步行和骑行分段可在用户明确操作后交给已安装的高德地图；失败时不回退 Google 或浏览器。
- 高德 Android SDK 使用单独、版本化隐私同意；未同意或撤回后不初始化高德地图。
- 后端为 Google 与高德分别执行原子额度预留、费用熔断、响应上限、全局并发限制和安全错误归一化。
- 保持 Room schema 2；v0.2.4 行程覆盖升级后保留 WGS84 点位、顺序、设置与进度，并在首次继续前重新分类和刷新路线。
