## Status and evidence rules

- **V - implemented and verified at the stated scope:** the row names the passing evidence and its limits. This does not imply all-device or live-provider acceptance.
- **I - incomplete:** implementation may exist, but a required behavior, final-source rerun or meaningful acceptance observation is missing.
- **B - externally blocked:** the stated external prerequisite prevents the required check. No substitute or waived gate is assumed.
- When a grouped row contains a remaining gate, its overall status is I or B even if some subrequirements already pass.
- Synthetic data, Compose map placeholders, genuine SDK markers, authenticated base maps and physical navigation are different evidence classes. Activity relaunch is not process-death recovery. TalkBack accessibility actions do not establish audible speech or human gesture usability.
