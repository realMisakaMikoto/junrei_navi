# 巡礼手帖 v0.2.6

## 本次更新

- 改进发现页和地图交互、点位展示及大字体适配。
- 修复巡礼点图片地址与尺寸处理，兼容旧图片引用，完善加载失败后的重试。
- 修复目录详情合并与刷新状态，防止迟到响应覆盖已验证数据。
- 地图移动后立即取消旧视野的批量选点资格，避免误选旧范围。
- 持久保存规划草稿，进程重建后恢复输入；缺失或损坏时提供可操作的返回路径。
- 将附近排序移至可取消的后台计算，复用距离结果。
- 增加地图定位圆点与方向显示，位置过期或方向不可靠时仅显示圆点。

## 兼容与已知限制

Android 8.0（API26）及以上；应用版本 `0.2.6`，版本代码 `12`，沿用既有签名证书，可覆盖安装。

本版按维护者 2026-10-16 的决定接受当前候选和已知限制。完整地图性能矩阵、部分真机传感器与地理底图场景尚未验证；API26 的原生高德支持不作通过承诺。已知限制与原始失败记录保留在[验收记录](FRONTEND_FIX_ACCEPTANCE.md#2026-10-16-维护者接受与收尾)。

不包含新的后端部署。客户端继续使用既有兼容的 v2 服务路径；本次发布不变更生产配额。
