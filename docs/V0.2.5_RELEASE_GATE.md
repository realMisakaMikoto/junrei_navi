# v0.2.5 双地图发布门禁

releaseGateStatus: BLOCKED

状态：**BLOCKED / 不得部署或发布**

核查日期：2026-08-09

本文只记录门禁和证据位置，不保存 API Key、签名密钥、服务账号、密码、Token、原始 IP、坐标或路线正文。敏感材料必须保存在仓库外的受限系统中；仓库只记录脱敏后的工单编号、适用范围、审核结论和校验值。

## 当前结论

v0.2.5 可以在本地使用合成边界夹具验证分类、提供方隔离、坐标系保护、配额原子性和兼容协议，但当前仓库没有可用于生产的中国大陆边界包，也没有足以复核双地图同一应用用途的书面授权、地图审核材料、独立生产密钥或已批准的额度值。因此：

- 不得把测试夹具作为真实行政边界或公开地图数据发布。
- 不得启用中国大陆生产路线、地图或外部交接。
- 不得把目标文件中的任意凭据写入源码、配置样例、日志、构建产物或命令记录。
- 不得部署 v0.2.5 后端、创建 RC/稳定标签、上传 APK、替换现有 v0.2.4 服务或宣称发布完成。
- v0.2.4 的历史发布记录和公开资产保持不变。

## 硬门禁证据

以下项目必须全部完成，并在 `docs/releases/v0.2.5.md` 中记录可复核的脱敏证据后，才允许进入生产候选部署：

- [ ] Google Maps Platform 书面确认：明确覆盖同一 Android 应用按行程地区互斥使用 Google Navigation/Routes 与高德地图/Web 服务；确认不会把 Google 内容与非 Google 地图共同显示或混用。
- [ ] 高德开放平台书面确认：明确覆盖 Android 地图 SDK、Web 服务 API、坐标转换、路线规划和高德地图 App URI 交接的实际应用、包名、签名及生产域名。
- [ ] 软件许可复核：当前 `LICENSE` 的专有 SDK 链接例外只列出 Google Navigation 与 Firebase，不覆盖高德 SDK。须由版权所有者明确批准并更新例外，或由法律复核确认其他可分发方案；自动化实现不得自行替版权所有者改变许可授权。
- [ ] 官方或有明确再分发权的数据包：能独立判定 `MAINLAND_CHINA`、`CHINA_OFFICIAL_MAP_ONLY`、香港、澳门、台湾、日本和其他地区；不得使用 Natural Earth、中国外包矩形或通用开源边界代替中国生产判定。
- [ ] 数据来源与许可：记录供应方、原始下载地址、版本、取得日期、许可文本、再分发范围、源文件 SHA-256 和派生文件 SHA-256。
- [ ] 地图审核：记录主管机关、审图号或适用的正式审核结论、审核日期、适用版本、允许的裁剪/缩放/叠加范围；任何派生变化均重新确认审核要求。
- [ ] Android 与后端镜像一致：两端生产资产的规范化内容 SHA-256、`regionDataVersion` 和分类夹具输出完全一致，损坏、缺失、重叠或边界不确定时均拒绝请求。
- [ ] 独立 Android 高德 Key：绑定 `cn.anitabi.navigator` 和正式/调试签名，且只开放所需 Android SDK；不得复用 Web 服务 Key。
- [ ] 独立高德 Web 服务 Key 与数字签名材料：只通过后端只读 secret 文件注入，权限和来源限制已核对；不得进入 APK、Git、日志或备份。
- [ ] Google Android Key、Firebase Android 配置和 Google 服务账号继续保持各自最小权限与现有隔离；未扩大到非必要 API。
- [ ] 高德每日/月度硬上限和 Google 月度硬上限已由负责人书面确认；配置缺失、恢复回退或审计异常时对应计费提供方关闭。
- [ ] v1 精确停止时间已记录为带时区的 UTC 时间，满足 v0.2.5 正式发布后 14 天；此前中国请求立即拒绝，此后全部 v1 POST 返回 `426`。
- [ ] 中文隐私说明、首次同意、关于页、第三方署名和应用商店披露已由负责人确认；高德隐私接口在任何 SDK 调用或 MapView 创建之前执行。
- [x] GitHub Actions 供应链复核：`release.yml` 中每个第三方 Action 都已固定到从官方仓库 tag 独立解析、并核对存在 `action.yml` 的完整提交 SHA；不得以浮动 major/tag 进入 `READY`。
- [ ] `v0.2.5-release` Environment 只允许受保护默认分支部署，要求独立复核且禁止发起人自批；已配置只在最终发布步骤使用、仅有本仓库 Contents 写权限的 `ANITABI_RELEASE_TOKEN`。

## 进入发布前的验证

- [ ] 后端类型检查、单元/并发测试、生产依赖审计、Docker 构建、Compose 配置校验、只读容器 smoke、备份/恢复和所有提供方 fail-closed 测试通过。
- [ ] Android JVM 测试、API 26/API 37 instrumentation、Debug/Release Lint、R8、源码/APK 凭据审计、固定签名和覆盖升级通过。
- [ ] 权威边界夹具覆盖大陆、官方地图专用区、香港、澳门、台湾、日本、其他、近海、孔洞、边界、重叠、未解析和损坏元数据；Android 与后端结果逐项一致。
- [ ] 真实 Google 测试证明非中国请求只到 Google；真实高德测试证明中国请求只到高德；代理/防火墙日志使用脱敏计数，不记录坐标或正文。
- [ ] 至少五段中国大陆真实路线覆盖驾车、骑行、步行和公交的支持/降级路径；地图提供方切换前销毁旧 MapView，屏幕上始终只有一个地图 SDK。
- [ ] WGS84 只用于持久化和跨组件协议；GCJ-02 只用于高德上游响应和高德地图绘制；任何提供方/坐标系不一致均失败而不是猜测或转换后混画。
- [ ] 无线实体设备使用 `adb connect 192.168.31.36:5555` 验证，但不运行会覆盖个人数据的整套 `connectedAndroidTest`，不卸载、不清数据，并保留脱敏证据。

## 证据记录规则

1. 每项证据记录负责人、核查日期、适用产品/版本、外部工单或合同编号、脱敏结论和仓库外保存位置；不得粘贴原文中的秘密。
2. 外部网页只作为当前规则参考，不能替代针对本应用用途的书面授权。
3. 合成测试边界必须带有显著的 `TEST_ONLY` 标识，且生产构建不能加载它。
4. 任一硬门禁失效、数据版本变化、Key 重建、包名/签名变化或地图渲染方式变化，都重新关闭门禁。
5. 只有所有复核人签字、实际候选提交固定并完成验证后，才把本文件状态改为 `READY`；发布结果另记入 `docs/releases/v0.2.5.md`。
6. 状态变为 `READY` 后，复核人在禁止发起人自批、且只允许受保护默认分支部署的 `v0.2.5-release` GitHub Environment 中登记精确候选提交、私有 HTTPS 地区资产位置、完整文件 SHA-256、数据版本和最小权限发布 Token；批准值不得存入候选提交，以免形成无法满足的自引用提交校验。
7. 发布只通过默认分支最新远端提交上的手动工作流发起，并只接受已经存在的 `v0.2.5` 或 `v0.2.5-rc.N` 标签。工作流先核对自身提交仍是远端默认分支顶端，再从远端解析标签、匹配受保护候选提交并无凭据地获取精确提交；构建任务只有只读仓库权限，发布任务在独立 Runner 中重新核对标签对象、提交、APK 哈希和 APK 内地区资产哈希后，才在最后一步短暂使用发布 Token。
8. Action 当前固定为：`actions/setup-node@v6`、`actions/setup-java@v5`、`android-actions/setup-android@v4`、`actions/upload-artifact@v7` 和 `actions/download-artifact@v8` 各自官方 tag 在 2026-08-09 解析得到的完整提交 SHA。任何升级都必须重新解析官方 ref、核对 action 元数据并复核完整 SHA，不能只改注释中的版本号。
