## 当前结论

v0.2.5 已从天地图正式交付页和 GSI 官方下载取得固定源文件，在 Git 忽略路径生成可重复的生产地区候选资产，并由 Android/后端对同一字节文件完成校验和及七类代表点核对。来源、公开许可、源/派生哈希和审图号见 [`REGION_DATA_PROVENANCE_v0.2.5.md`](REGION_DATA_PROVENANCE_v0.2.5.md)。版权所有者已加入未修改高德 Android 3D 地图 SDK 的窄范围链接/分发例外，独立高德 Android/Web Key、数字签名和个人开发者测试额度也已过控制台复核；但双地图同一应用用途的书面提供方授权、高德应用合规/正式生产许可、独立发布复核和其余真实候选证据仍未在本门禁登记。因此：

- 不得把测试夹具作为真实行政边界或公开地图数据发布。
- 不得启用中国大陆生产路线、地图或外部交接。
- 不得把目标文件中的任意凭据写入源码、配置样例、日志、构建产物或命令记录。
- 不得部署 v0.2.5 后端、创建 RC/稳定标签、上传 APK、替换现有 v0.2.4 服务或宣称发布完成。
- v0.2.4 的历史发布记录和公开资产保持不变。

## 高德控制台复核（2026-08-09）

- 账号当前为个人开发者。Android Key 与 Web 服务 Key 相互独立；未记录任何 Key 或私钥值。
- Android Key 绑定 `cn.anitabi.navigator`，正式 SHA-1 与公开 v0.2.4 固定 RSA-4096 签名证书一致；调试 SHA-1 未配置。
- Web 服务 Key 已启用单一生产出口 IP 白名单与数字签名。对应 Web Key、签名私钥和 Android Key 已重新写入 GitHub `v0.2.5-release` 受保护 Secrets；尚未安装为 VPS 生产只读 secret 文件。真实接口测试只使用临时的 root-only 文件，测试后已删除。
- 基础 LBS 月配额为 150,000 次；驾车、骑行、步行、公交、距离、地理/逆地理编码和坐标转换均显示 3 次/秒上限。后端另以全进程最多两个并发、任意滚动一秒最多三个请求启动进行保护。
- 应用合规状态仍为“待审核”。控制台明确说明个人 Key/配额只供短期、少量测试；公开分发、上架、收费/广告、组织内上线或长期/大量调用需要技术服务许可。因此这些事实只解除密钥分离、签名绑定和测试额度疑问，不构成生产授权，也不改变 `BLOCKED` 状态。

## 高德真实接口测试（2026-08-09）

- 从已绑定白名单的 VPS 出口运行了有界、串行、脱敏的真实提供方 smoke；驾车、步行、骑行和公交四种模式均通过，证明 Web Key、数字签名和出口 IP 绑定可用于短期测试。
- 首次测试发现当前 v5 骑行响应把总时长放在 `path.duration`，公交响应把路线几何放在 `polyline.polyline`，站点字段使用 `departure_stop` / `arrival_stop`。后端已按端点分别解析并用对应结构夹具覆盖；修复后后端 78/78 测试和四模式真实 smoke 全部通过。
- 测试日志只保留模式级通过/失败结果；未记录请求 URL、坐标、Key、签名或原始响应。VPS 临时脚本与凭据文件已删除，浏览器和自动化会话中的凭据引用已清除。
- 该结果不替代生产技术服务许可、应用合规审核、权威地区数据、双提供方书面授权、至少五段路线和端到端提供方隔离证据，因此发布状态仍为 `BLOCKED`。

## 证据记录规则

1. 每项证据记录负责人、核查日期、适用产品/版本、外部工单或合同编号、脱敏结论和仓库外保存位置；不得粘贴原文中的秘密。
2. 外部网页只作为当前规则参考，不能替代针对本应用用途的书面授权。
3. 合成测试边界必须带有显著的 `TEST_ONLY` 标识，且生产构建不能加载它。
4. 任一硬门禁失效、数据版本变化、Key 重建、包名/签名变化或地图渲染方式变化，都重新关闭门禁。
5. 只有所有复核人签字、实际候选提交固定并完成验证后，才把本文件状态改为 `READY`；发布结果另记入 `docs/releases/v0.2.5.md`。
6. 状态变为 `READY` 后，复核人在禁止发起人自批、且只允许受保护默认分支部署的 `v0.2.5-release` GitHub Environment 中登记精确候选提交、私有 HTTPS 地区资产位置、完整文件 SHA-256、数据版本和最小权限发布 Token；批准值不得存入候选提交，以免形成无法满足的自引用提交校验。
7. 发布只通过默认分支最新远端提交上的手动工作流发起，并只接受已经存在的 `v0.2.5` 或 `v0.2.5-rc.N` 标签。工作流先核对自身提交仍是远端默认分支顶端，再从远端解析标签、匹配受保护候选提交并无凭据地获取精确提交；构建任务只有只读仓库权限，发布任务在独立 Runner 中重新核对标签对象、提交、APK 哈希和 APK 内地区资产哈希后，才在最后一步短暂使用发布 Token。
8. Action 当前固定为：`actions/setup-node@v6`、`actions/setup-java@v5`、`android-actions/setup-android@v4`、`actions/upload-artifact@v7` 和 `actions/download-artifact@v8` 各自官方 tag 在 2026-08-09 解析得到的完整提交 SHA。任何升级都必须重新解析官方 ref、核对 action 元数据并复核完整 SHA，不能只改注释中的版本号。
