# 巡礼手帳

> 使用 [Anitabi](https://anitabi.cn) 巡礼数据制作的第三方开源 Android 应用，与 Anitabi 官方没有隶属关系。

搜索喜欢的动画，选择想去的巡礼点，生成步行、骑行、驾车或公交行程。支持多作品联合选点，并按行程所在地区使用 Google 或高德地图。

## 地图与导航

| 行程地区 | 地图与路线 | 导航方式 |
| --- | --- | --- |
| 中国大陆及中国官方地图专用区域 | 高德地图、高德路线 | 按段打开手机上的高德地图 |
| 日本公交行程 | Google 地图、本地访问顺序 | 按段打开 Google 地图查询公交 |
| 香港特别行政区、澳门特别行政区、中国台湾及其他地区；日本非公交行程 | Google 地图、Google Routes | 道路模式使用应用内 Google 导航；公交按段显示实际查询结果 |

起点和全部目的地必须属于同一地图提供方。跨 Google/高德区域的行程会提示调整选点；日本与非日本地点也不能混合为一条公交行程。

搜索结果涉及不同地图地区时，可显式切换 Google/高德地图。每张地图只显示对应地区的点位，完整列表与已选地点保留；地图加载失败时可继续使用列表选点。应用不会把两家地图拼接显示，也不会将一家提供方的路线画到另一张地图上。

Android 与后端分别使用同一版本的地区数据进行判断；无法可靠判区、地区数据缺失或版本不一致时会停止请求，避免错误分流。

## 你可以做什么

- 通过 Bangumi 搜索动画，从 Anitabi 加载巡礼点与图片。
- 同时选择多部作品，在地图或列表中选点，也可批量选择地图范围内的地点。
- 自动排序并分批规划步行、骑行、驾车或公交行程。
- 查看支持地区的路线、距离、预计时间、站点与换乘详情。
- 调整未完成的后续地点，保存行程顺序、完成状态和导航进度。
- 在外部地图导航期间使用通知、悬浮窗或应用内控制，进行到达确认、停留、下一段和暂停。
- 在高德路线暂时不可用时，明确选择“仅按当前顺序分段打开高德地图”；此模式不显示伪造的路线详情或预计时间，也不回退 Google。

总行程没有固定的产品级点数上限，但仍受单次请求限制、设备资源和项目共享额度影响。

## 第一次使用

1. 阅读用途和隐私说明，完成定位、通知及后台运行导览。
2. 使用高德地图前，在导览或“关于”中单独允许高德 SDK 隐私授权；可随时撤回。
3. 搜索并选择一部或多部作品。
4. 在地图或列表中选择巡礼点；混合地图地区的结果可通过上方入口切换地图。
5. 选择出行方式、起点、终点规则与停留时间，生成行程。

Google 地图和应用内 Google 道路导航依赖 Google Play 服务。高德分段导航需要安装高德地图；日本公交建议安装 Google 地图。首次导览中的电池优化、后台锁定和悬浮窗设置用于提高连续导航稳定性，不会阻止完成导览。

官方安装包不要求你申请 API Key、注册邮箱账号或向项目付费。自行编译时需要配置自己的服务与密钥，见[构建说明](docs/BUILD.md)。

## 网络与共享额度

地图、搜索和新路线需要网络；离线时可查看已保存的点位、顺序和进度，但不能保证刷新地图或路线。

路线请求使用 Firebase 匿名身份鉴权，不设置个人每日额度。后端使用 HMAC-IP 防滥用限速，并在调用提供方前预留项目共享额度，失败的上游调用不退款。

当前服务配置为：

- Google：每月最多 9,000 个矩阵元素、9,000 次路线请求及 900 个导航目的地预留。
- 高德：坐标转换、逆地理编码、距离测量和路线四类调用，分别限制为每日 200 次、每月 200 次，所有用户共享。
- 一次多点行程可能消耗多次调用；步行、骑行矩阵和多段公交尤其容易消耗较多额度。当前额度较小，不承诺不限量或持续可用。

达到限额、网络异常或服务维护时，新路线可能暂时不可用，本地行程和进度会保留。后台运行设置也不能绕过 Android 的定位、通知和前台服务限制。

## 公交与地区限制

- 日本公交先在本机判断完整行程地区并排序，再由用户逐段打开 Google 地图。路线、班次和是否有公交由 Google 地图决定，应用不会读取或推断外部查询结果。
- 中国大陆公交由高德查询，支持现在或指定时间出发；不支持“指定到达时间”，也不支持任意交通工具组合筛选。
- 其他地区公交以 Google Routes 实际覆盖为准，消费版地图能找到路线不代表 API 一定能返回相同结果。
- 没有线路、接口故障、额度不足和版本不兼容会分别提示。Google 公交的无线路详情可用于查看端点并主动跳转 Google 地图核对。

## 隐私与数据

- 不要求邮箱、姓名或密码。Firebase 匿名身份只用于路线访问鉴权。
- 规划时发送坐标、出行方式和相关时间选项，后端独立判区后选择对应提供方。
- 本地保存的点位和请求坐标为 WGS84；高德返回的 GCJ-02 几何仅用于高德地图绘制。
- Google 与高德的路线、折线、步骤、预计时间及公交详情仅驻留当前进程内存，不写入行程数据库。
- 本地持久化保存作品、点位、顺序、设置、完成状态和导航进度，以及必要的授权状态与公共数据缓存；Android 系统备份和设备迁移关闭。
- 用户主动分段交接时，精确起终点会发送给手机上的对应地图应用。
- Analytics 和 Crashlytics 默认关闭，可分别选择加入和撤回。
- 项目日志不记录令牌、原始 IP、坐标、作品名称、搜索词或路线正文。

完整说明见[隐私政策](PRIVACY.md)与[安全策略](SECURITY.md)。
