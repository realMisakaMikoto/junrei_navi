# 巡礼手帳

用 [Anitabi](https://anitabi.cn) 的巡礼数据做的第三方 Android 应用，和 Anitabi 官方没有隶属关系。

搜动画，挑巡礼点，生成步行、骑行、驾车或公交行程。可以同时选多部作品的点位，按行程所在地区决定用 Google 地图还是高德地图。

这一版沿用已经过 CI、签名检查并人工验收的安装包，没有重新构建。变化与验证记录见 [v0.2.5 发布说明](docs/RELEASE_NOTES_v0.2.5.md) 和 [发布记录](docs/releases/v0.2.5.md)。

## 地图和导航

| 行程地区 | 地图与路线 | 导航 |
| --- | --- | --- |
| 中国大陆及中国官方地图专用区域 | 高德地图、高德路线 | 按段打开手机上的高德地图 |
| 日本公交行程 | Google 地图、本地访问顺序 | 按段打开 Google 地图查公交 |
| 港澳台及其他地区；日本非公交行程 | Google 地图、Google Routes | 道路模式用应用内 Google 导航，公交按段显示实际查询结果 |

起点和所有目的地必须属于同一家地图。跨 Google / 高德区域的行程会提示调整选点，日本和非日本地点也不能拼成一条公交行程。

搜索结果跨地区时可以手动切 Google / 高德。每张地图只画对应地区的点位，完整列表和已选地点都保留；地图加载失败也能继续用列表选点。应用不把两家地图拼在一起显示，也不会把一家的路线画到另一张地图上。

Android 和后端用同一版本的地区数据判断，判不了区、数据缺失或版本不一致时会停下来，不做错误分流。

## 主要功能

- 用 Bangumi 搜动画，从 Anitabi 加载巡礼点和图片。
- 多部作品同时选点，在地图或列表里挑，也可以框选地图范围内的点。
- 自动排序并分批规划步行、骑行、驾车或公交行程。
- 查看路线、距离、预计时间、站点和换乘详情。
- 调整没走完的后续地点，保存顺序、完成状态和导航进度。
- 跳出去导航时有通知、悬浮窗或应用内控制，可以确认到达、停留、切下一段和暂停。
- 高德路线暂时不可用时，可以明确选「仅按当前顺序分段打开高德地图」。这个模式不显示编造的路线详情或预计时间，也不回退到 Google。

总行程没有产品层面的点数上限，但受单次请求限制、设备资源和项目共享额度影响。

## 第一次用

1. 读完用途和隐私说明，完成定位、通知和后台运行导览。
2. 用高德地图前，要在导览或「关于」里单独同意高德 SDK 的隐私授权，随时可以撤回。
3. 搜索并选择一部或多部作品。
4. 在地图或列表里选巡礼点。混了不同地图地区的结果用上方入口切换。
5. 选出行方式、起点、终点规则和停留时间，生成行程。

Google 地图和应用内的 Google 道路导航依赖 Google Play 服务。高德分段导航要装高德地图，日本公交建议装 Google 地图。首次导览里的电池优化、后台锁定和悬浮窗设置是为了连续导航稳定，不设置也能走完。

官方安装包不需要申请 API Key、注册邮箱或付费。自己编译要配自己的服务和密钥，见 [构建说明](docs/BUILD.md)。

## 网络和共享额度

地图、搜索和新路线都需要联网。离线时能看已保存的点位、顺序和进度，但刷新地图和路线不保证。

路线请求用 Firebase 匿名身份鉴权，没有个人每日额度。后端用 HMAC-IP 做防滥用限速，调用上游之前预留项目共享额度，失败的上游调用不退款。

当前服务配置：

- Google：每月最多 9,000 个矩阵元素、9,000 次路线请求，900 个导航目的地预留。
- 高德：坐标转换、逆地理编码、距离测量和路线四类调用，各限每日 200 次、每月 200 次，所有用户共享。

一次多点行程可能吃掉多次调用，步行、骑行矩阵和多段公交尤其费额度。额度不大，不承诺不限量或长期可用。

到限额、网络异常或服务维护时新路线可能暂时不可用，本地行程和进度不受影响。后台运行设置也绕不过 Android 的定位、通知和前台服务限制。

## 公交和地区限制

- 日本公交在本机判断完整行程地区并排序，然后逐段打开 Google 地图，路线、班次和有没有公交由 Google 地图决定，应用不读也不推断外部查询结果。
- 中国大陆公交走高德，支持现在出发或指定出发时间；不支持指定到达时间，也不支持任意交通工具组合筛选。
- 其他地区公交以 Google Routes 实际覆盖为准。消费版地图能找到路线，不代表 API 一定返回一样的结果。
- 没线路、接口故障、额度不足和版本不兼容会分别报错。Google 公交的「无线路详情」可以用来查看端点并跳去 Google 地图核对。

## 隐私

- 不要邮箱、姓名和密码。Firebase 匿名身份只用于路线接口鉴权。
- 规划时发送坐标、出行方式和时间选项，后端独立判区后选择对应提供方。
- 本地保存的点位和请求坐标是 WGS84；高德返回的 GCJ-02 几何只用于高德地图绘制。
- Google 和高德的路线、折线、步骤、预计时间和公交详情只留在当前进程内存，不写入行程数据库。
- 本地持久化保存作品、点位、顺序、设置、完成状态、导航进度，以及必要的授权状态和公共数据缓存。系统备份和设备迁移是关的。
- 用户主动分段交接时，精确起终点会发给手机上的对应地图应用。
- Analytics 和 Crashlytics 默认关闭，可以分别选择加入和撤回。
- 项目日志不记录令牌、原始 IP、坐标、作品名称、搜索词和路线正文。

完整说明见 [隐私政策](PRIVACY.md) 和 [安全策略](SECURITY.md)。
